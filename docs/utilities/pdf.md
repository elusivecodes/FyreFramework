## Create a PDF

Configure the browser executable for the current environment, then save or return the generated bytes:

```php
use Fyre\Utility\Pdf;

$pdf = Pdf::createFromHtml(
    '<h1>Invoice</h1><p>Thanks!</p>',
    [
        'binaryPath' => '/usr/bin/chromium',
        'timeout' => 10000,
    ]
);

$pdf->save('tmp/invoice.pdf');
```

Use absolute asset URLs or add a `<base>` element when HTML refers to stylesheets, images, or fonts. `createFromHtml()` renders a Base64 `data:` URL, so ordinary relative URLs have no application base.

## Environment requirements

- Chrome or Chromium must be installed, executable by PHP, and usable in headless mode.
- The destination parent directory must already exist and be writable.
- The PHP process must permit `shell_exec()`.
- The browser process must be able to access any URL and external asset being rendered.

## Options

Options are copied into each `Pdf` instance:

| Option | Type | Default | Behavior |
| --- | --- | --- | --- |
| `binaryPath` | `string` | `google-chrome` | executable name or path passed to the shell |
| `timeout` | `int` | `5000` | milliseconds passed to Chrome's `--timeout`; must not be negative |

Unknown option keys are ignored by construction because only these two resolved values are read.

## Method guide

The methods below use the `Pdf` setup shown above.

### Creation

| Method | Source behavior |
| --- | --- |
| `Pdf::createFromHtml(string $html, array $options = []): static` | Base64-encode HTML into a `data:text/html` URL |
| `Pdf::createFromUrl(string $url, array $options = []): static` | pass a URL or file path directly to the browser |
| `new Pdf(string $source, array $options = [])` | use the supplied source directly |

Neither factory launches the browser; generation begins when output is requested.

### Output and inspection

| Method | Behavior |
| --- | --- |
| `save(string $filePath): void` | launch the browser and write a new PDF file |
| `toBinary(): string` | generate through a temporary path, read the bytes, and remove the temporary output |
| `getBinaryPath(): string` | resolved executable option |
| `getTimeout(): int` | resolved timeout in milliseconds |

`save()` rejects an empty path and an existing destination. It does not provide an overwrite option.

## Process and file behavior

- Generation uses `--headless`, `--deterministic-mode`, `--no-pdf-header-footer`, `--print-to-pdf`, and the configured `--timeout`.
- The executable, source, and output arguments are shell-escaped. Browser stderr/stdout is discarded after execution.
- Success is determined by whether the expected output file exists; the browser exit code and output are not exposed.
- `toBinary()` closes the temporary handle before invoking Chrome and removes the generated file in a `finally` block.
- Failures to create temporary storage, generate a file, or read its bytes throw a `RuntimeException`.
- `Pdf` supports instance and static macros.
