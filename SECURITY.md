# Security Policy

Use this policy when reporting a security vulnerability in FyreFramework.

## Supported Versions

Security fixes are provided for the latest published release. Older releases may not receive security updates.

## Reporting a Vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/fyrephp/framework/security/advisories/new).

Do not open a public issue for a suspected vulnerability. Include the affected version, expected impact, reproduction steps, and any known mitigations when that information is available.

Reports will be reviewed and handled according to their impact and complexity. No fixed response or resolution time is guaranteed.

Please allow time for a fix and coordinated release before publicly disclosing a vulnerability.
